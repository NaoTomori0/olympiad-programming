# Олимпиадное программирование и математика

*Читать на других языках: [English](README.md).*

Мой личный репозиторий для тренировок по спортивному программированию. Основной упор сделан на прохождение курса **«Академия ИТМО: пилотный курс»** на Codeforces и изучение математической базы.

## 📂 Структура репозитория

* `itmo-academy/` — Решения задач по темам Академии ИТМО (Деревья отрезков, Суффиксные массивы, Z-функция и др.).
* `notes.cpp` — Теоретические конспекты, формулы и шпаргалки по математике и алгоритмам.

## 🛠️ Стек технологий

* **Язык программирования:** C++ (GCC)
* **Платформа:** [Codeforces](https://codeforces.com)
* **Среда разработки:** VS Code / Vim / NeoVim

## 📝 Правила оформления

* Имена файлов строго соответствуют буквам задач (например, `A.cpp`, `B.cpp`).
* В названиях папок и файлов используются только английские буквы, строчный регистр и дефисы вместо пробелов.
* Решения распределены по шагам в точном соответствии с программой курса.
